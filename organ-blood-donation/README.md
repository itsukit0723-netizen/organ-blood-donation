# REPORT｜「意思」と「支え合い」臓器提供と献血

保健の授業で発表したプレゼン資料（全15枚）を、そのままの雰囲気で1ページのWebサイトにしたものです。

## 開き方

`index.html` をダブルクリックしてブラウザで開くだけです。ビルドもサーバーも要りません。

## ファイル構成

```
organ-blood-donation/
├─ index.html          … ページ本体
├─ css/style.css       … 配色・レイアウト・アニメーション
├─ js/main.js          … スクロール連動の動き、カウントアップ、設定パネル
└─ assets/
   ├─ art/             … プレゼンのスライドから切り出したイラスト（背景を透過処理）
   ├─ illust/          … 「イラスト素材」フォルダの線画（1体＝1ファイル）
   └─ slides/          … 元のプレゼン画像 1.png〜15.png（サイトでは未使用・参照用）
```

## デザインの決まりごと

- 配色はプレゼンから抽出した3色のみ
  - 黄 `#FADE6B` ／ 黒 `#302F28` ／ 白 `#FFFFFF`
- 見出しは Zen Kaku Gothic New（太いゴシック）、英語ラベルと数字は Roboto Mono
- 見出しの上に小さい英語ラベル（`Contents` `Intention` `Reality in Japan` `Whose Choice` `Blood Donation`）、
  見出しの下に黒い罫線 ── というプレゼン共通のレイアウトを全セクションで踏襲
- 白い節の下端に黄色の帯、章の区切りは `01`〜`04` の全面黄色ページ
- イラストは白黒の線画のみ。アイコンも同じタッチでSVGで描き起こし

## 動きについて

- すべて `IntersectionObserver` によるスクロール連動です。画面に入ったセクションから動き出します。
- イラストは1枚の線画を頭・腕・胴・脚などの領域に切り分け（`js/main.js` の `SPLITS`）、
  パーツごとに別方向・別タイミングでずれた位置から登場し、最後に元の1枚へぴったり組み上がります。
- 登場後もずっと続く動きは、**イラスト全体をゆっくり浮かせる**形にしています。
  胴と脚のように線がつながっている境目を個別に動かし続けると、切れ目に背景が覗いてしまうためです。
  例外として、02章の波模様のように元の絵の中で完全に離れているパーツは、そのまま単独で漂わせています。
- そのほか：罫線が左から伸びる／目次の番号が横から入る／数値のカウントアップ／棒グラフが伸びる／
  黄色のマーカーが左から引かれる／矢羽根が順番に現れる／検索窓に「意思表示」がタイプされる／
  きらめき（スパークル）がまたたく。
- OSの「視差効果を減らす」設定（`prefers-reduced-motion`）を尊重します。
  右下のボタン → 「動きを減らす」でも切り替えられ、設定はブラウザに保存されます。

## レスポンシブ

PC（横幅1440px前後）を基準に作っていますが、固定pxをほとんど使わず
`clamp()` と Grid/Flexbox で組んでいるので、そのままスマートフォンでも読めます。
1024px以下で2カラムが1カラムに、640px以下で表組みと矢羽根がさらに縦積みになります。
