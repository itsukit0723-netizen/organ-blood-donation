# REPORT｜「意思」と「支え合い」臓器提供と献血

保健の授業で発表したプレゼン資料（全15枚）を、そのままの雰囲気で1ページのWebサイトにしたものです。

## 開き方

`index.html` をダブルクリックしてブラウザで開くだけです。ビルドもサーバーも要りません。

## ファイル構成

```
organ-blood-donation/
├─ index.html          … ページ本体
├─ css/style.css       … PC版の配色・レイアウト・アニメーション
├─ css/mobile.css      … スマホ版（767px以下）の上書きだけを書いたファイル
├─ js/main.js          … スクロール連動の動き、カウントアップ、設定パネル
├─ dist/
│  └─ organ-blood-donation-1file.html
│                      … 画像もCSSもJSも全部入りの1枚版（配布用）
├─ .nojekyll           … GitHub Pages 用（消さないでください）
├─ .gitignore          … Windowsが作る不要ファイルを上げないための設定
└─ assets/
   ├─ ogp.png          … LINEなどにリンクを貼ったときのプレビュー画像
   ├─ favicon.svg / apple-touch-icon.png … タブとホーム画面のアイコン
   ├─ art/             … プレゼンのスライドから切り出したイラスト（背景を透過処理）
   ├─ illust/          … 「イラスト素材」フォルダの線画（1体＝1ファイル）
   └─ slides/          … 元のプレゼン画像 1.png〜15.png（サイトでは未使用・参照用）
```

`css/style.css`（PC版）には手を入れていません。スマホ版は `css/mobile.css` で
`@media (max-width: 767px)` の中から上書きしているだけなので、
どちらか片方だけ直しても、もう片方には影響しません。

## デザインの決まりごと

- 配色はプレゼンから抽出した3色のみ
  - 黄 `#FADE6B` ／ 黒 `#302F28` ／ 白 `#FFFFFF`
- 見出しは Zen Kaku Gothic New（太いゴシック）、英語ラベルと数字は Roboto Mono
- 見出しの上に小さい英語ラベル（`Contents` `Intention` `Reality in Japan` `Whose Choice` `Blood Donation`）、
  見出しの下に黒い罫線 ── というプレゼン共通のレイアウトを全セクションで踏襲
- 白い節の下端に黄色の帯、章の区切りは `01`〜`04` の全面黄色ページ
- イラストは白黒の線画のみ。アイコンも同じタッチでSVGで描き起こし

## スマホ版で変えたところ

- イラストを見出しの横に戻し、サイズを小さくした（PC版と同じ「文字は左・絵は右」の構図）
- PCで右側に出る章ドットナビを、**画面下に固定した章バー**として常に表示。
  現在の章の名前がドットの上に出る
- 右下のボタンを、**章メニュー（目次）＋設定**をまとめた実用的なメニューに変更
  （PC版ではメニュー部分は非表示のまま）
- 見出しの字間・本文サイズ・余白をスマホ幅向けに調整
- 矢羽根の図解は縦並び＋下向きの矢印に、比較の2カラムは縦積みに

## 動きについて

- すべて `IntersectionObserver` によるスクロール連動です。画面に入ったセクションから動き出します。
- **画面から出て、もう一度入るたびに何度でも再生されます。**
  上へ戻って見返したときも、初回と同じようにアニメーションが最初から動きます
  （数値のカウントアップと検索窓のタイピングも同じく打ち直します）。
- イラストは1枚の線画を頭・腕・胴・脚などの領域に切り分け（`js/main.js` の `SPLITS`）、
  パーツごとに別方向・別タイミングでずれた位置から登場し、最後に元の1枚へぴったり組み上がります。
- 登場後もずっと続く動きは、**イラスト全体を大きく動かす**形にしています（弾む／左右に振れる／斜めに漂うの3種類を、
  イラストごとに速さを変えて割り当て）。
  胴と脚のように線がつながっている境目を個別に動かし続けると、切れ目に背景が覗いてしまうためです。
  例外として、02章の波模様のように元の絵の中で完全に離れているパーツは、そのまま単独で漂わせています。
- そのほか：罫線が左から伸びる／目次の番号が横から入る／数値のカウントアップ／棒グラフが伸びる／
  黄色のマーカーが左から引かれる／矢羽根が順番に現れる／検索窓に「意思表示」がタイプされる／
  きらめき（スパークル）がまたたく。
- OSの「視差効果を減らす」設定（`prefers-reduced-motion`）を尊重します。
  右下のボタン → 「動きを減らす」でも切り替えられ、設定はブラウザに保存されます。

## レスポンシブ

PC（横幅1440px前後）を基準に作っています。固定pxをほとんど使わず
`clamp()` と Grid/Flexbox で組んでいるので、幅に応じて自動で切り替わります。

| 画面幅 | 効いているCSS |
| --- | --- |
| 1025px 以上（PC） | `style.css` のみ ＝ 納品時のPC版そのまま |
| 768〜1024px（タブレット） | `style.css` の1カラム化 |
| 767px 以下（スマホ） | `style.css` ＋ `mobile.css`（スマホ専用の見た目） |

URLは1つで、開いた端末の幅を見て自動でPC版／スマホ版に切り替わります。
HTMLを2つに分けていないので、本文を直すときも `index.html` の1か所だけ直せば両方に反映されます。

## GitHubにアップロードして公開する

このフォルダは、**中身をそのままGitHubに上げるだけ**で公開できる状態にしてあります。
Gitのコマンドは使いません。ブラウザだけで完結します。

### 手順

1. github.com にログインし、右上の「＋」→ **New repository**
2. Repository name に `organ-blood-donation` などを入力し、**Public** を選んで **Create repository**
3. 次の画面の **uploading an existing file** をクリック
4. エクスプローラーで `organ-blood-donation` フォルダを開き、
   **中のファイル・フォルダを全部選んで**（フォルダごとではなく中身を）ドラッグ＆ドロップ
5. 下の **Commit changes** を押す
6. リポジトリの **Settings** → 左メニューの **Pages** →
   Source を **Deploy from a branch**、Branch を **main / (root)** にして **Save**
7. 1〜2分待つと Pages の画面にURLが出ます
   → `https://ユーザー名.github.io/organ-blood-donation/`

このURLをそのまま配れば、PCでもスマホでも同じリンクで開けます。

### アップロードするときの注意

- **`index.html` がいちばん上の階層に来るように**上げてください。
  `organ-blood-donation` フォルダごと上げると URL が `.../organ-blood-donation/organ-blood-donation/`
  のように一段深くなります（それでも表示はされます）。
- `.nojekyll` は隠しファイルです。エクスプローラーで見えないときは
  「表示」→「隠しファイル」にチェックを入れてから選んでください。
  もし上げ忘れても、このサイトは `_` で始まる名前を使っていないので問題なく表示されます。
- `assets/slides/`（元のプレゼン画像・約1.4MB）はサイトからは使っていません。
  容量を減らしたいときは、上げるときに外しても表示に影響はありません。

### 公開後にやると良いこと（任意）

`index.html` の中のこの行を、実際のURLに書き換えると、
LINEやXにリンクを貼ったときにプレビュー画像が出るようになります。

```html
<meta property="og:image" content="assets/ogp.png">
↓
<meta property="og:image" content="https://ユーザー名.github.io/organ-blood-donation/assets/ogp.png">
```

### GitHub Pages 向けにしてあること

- リンクはすべて**相対パス**。`https://ユーザー名.github.io/リポジトリ名/` のような
  サブフォルダ配信でも画像・CSS・JSが全部読み込めます（実際にその形で表示確認済み）
- ファイル名はすべて半角小文字。GitHubは大文字小文字を区別するため、
  Windowsでは動くのにネット上では画像が出ない、という事故を防いでいます
- `.nojekyll` を同梱（GitHubが余計な変換をせず、そのまま配信します）
- iPhoneのホームバー・ノッチにかからないよう、下の章バーに**セーフエリア**の余白を確保
- 古いiOSでも高さが崩れないよう `svh` に `vh` のフォールバックを併記
- 登場アニメーションでイラストが画面外へはみ出して**横スクロールが出ないよう**、
  スマホでは飛び出す量を抑え、`overflow-x` でも二重に押さえています
- タブのアイコン（favicon）と、iPhoneでホーム画面に追加したときのアイコンを用意
